# Ninja Adventure asset subset

Author: Pixel-Boy, created at Sparklin Labs.

Source: https://github.com/sparklinlabs/superpowers-asset-packs

Pinned commit: `e8674a03ab4456802f71f848c4df79eccca23f7a`

The unmodified PNG files come from `ninja-adventure/characters/` and
`ninja-adventure/background-elements/tileset.png` at that commit. `font8x8.png`
comes from `ninja-adventure/font8x8.png` at the same commit. Character
files are renamed `character-<number>.png` and `character-dog.png`; no raster
data was changed. The included README.md and LICENSE.txt are the upstream
repository's original files.

License: CC0 1.0 Universal. The original repository explicitly permits use,
modification and redistribution, including commercial games.

The runtime selects four civilian archetypes plus a traveler and dog. Its
AI outfit-color transformations are derived versions, also provided under CC0.
Room composition, office furniture and interface code are original to this fork.

The newer Ninja Adventure pack by Pixel-Boy and AAA was also considered, but
this build uses only the above pinned original GitHub files.
