# 人物基础模型替换

项目所有者要求用提供的 `7b51da2fd49357e33b60fda73ec15b27.glb` 替换游戏基础人物，
重新绑骨，保留原有动作、衣橱与交互逻辑。输入是带 PBR 贴图的静态模型，无骨骼和
动画，498762 个三角面。输入 GLB 与原参考 rig 均只读，交互中的 Blender 场景未使用。

## 适配范围

- 离线减面、拆分头发与衣服接触边并补面，最终 31917 个三角面、16057 个几何顶点
  （GLB 导出按材质/法线/顶点色拆分），运行时文件 2586480 字节。
  将贴图细节采样到顶点色，保留五个独立换色材质名和
  固定细节材质，不把原始 44MB 模型或大贴图载入每个角色。
- 保留原有 23 个骨骼的名称和层级，按新模型头身比重新布置关节，重新生成权重，
  每顶点最多四个影响并归一化；分开的头发区域随头部。合并既有动作中等价的
  骨骼影响，在最终 LOD 与四权重打包后，对七个代表姿态局部松弛异常接缝梯度；
  未改变动作曲线。源模型接触网格和自动材质分区仍是游戏尺度近似。
- 按新旧 rest basis 重映射原 OfficeIdle / OfficeWalk / OfficeSeated / OfficeDrink /
  OfficeExercise 的旋转与位移。坐姿 Root 补偿维持原归一化臀部座高，道具所用
  RightHand / RightArm / RightForeArm / Head 接口保留。
- 不修改 `worker-3d.js`、衣橱算法、外观覆盖、角色行为、场景物理和多智能体回合逻辑。
  仍使用原 v1 衣橱存储键；新模型是夹克、裙装和长发轮廓，下装 `pants` 色映射到裙装。
  不增加衣服/发型形状切换、手指表情、布料或头发物理。材质分区和顶点细节是游戏
  尺度近似，未宣称完整恢复源模型的高分辨率 PBR 纹理。

## 核验

模型专项真实 GLB 测试覆盖来源、面数和资源预算、五套动作、骨骼与归一权重、五种
实际材质换色、共享几何、独立骨架与动画状态、释放资源；手机叠加动作连续更新
180 帧不累积旋转，收起后手腕回到原位置。真实后发材质不继承臂骨，伸展接缝测试
要求边长比低于 5。来源和伸展断言均先失败，再在修正模型后通过。

完整 795 项单元测试通过，客户端生成一致性和 lint 通过（13 条既有警告）。独立
mock / Chrome 的 17 项检查覆盖 6 个同事加玩家、7 个上装色和4个肤色、v1 衣橱存储、
行走、拿起收起手机、Quiet motion、会议坐姿、退出返回位置与衣橱保留及画布数量，
无应用脚本错误。五套离线彩色姿态检查完成；独立复核按 30fps 扫描五套完整动作，
最大边长比：Idle 1.026、Walk 3.704、Seated 4.274、Drink 3.575、Exercise 4.385。
排除短于身高千分之一的边，这些数据用于发现异常牵拉，不代表完全没有形变。
浏览器的 58 FPS 是一次样本，不是持续性能基准。3152 原预览仍在线，且服务的插件
包与最新生成的 `client.js` 一致。输入 GLB 的 SHA-256 与初次读取一致。
