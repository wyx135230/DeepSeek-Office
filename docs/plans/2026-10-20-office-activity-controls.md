# 办公室设施的轻量交互

- 日期：2026-10-20
- 相关：项目所有者要求调研后改善设施提示、触发与打断；范围仅为场景表现与输入

## 调研与取舍

[FFXIV 官方操作手册](https://eu.finalfantasyxiv.com/game_manual/operation/)区分目标与确认交互；
[Minecraft 官方船只说明](https://www.minecraft.net/ko-kr/article/taking-inventory--boat)提供明确的键盘离开动作。
[Xbox 输入指南](https://learn.microsoft.com/en-us/xbox/accessibility/xbox-accessibility-guidelines/107)
强调输入方案应支持操作需求。由此为本项目选择「靠近显示短提示，确认进入，移动退出」：
这里只借鉴交互原则，界面、图标和实现原创，不复制游戏素材。

旧活动卡沿用了抽屉的 top/bottom 定位，少量文字也会撑满高度；沙发还需要打开卡片后
再按 Sit down。新样式显式取消上下拉伸，按内容决定高度。原暖白、鼠尾草绿、细边框
和 Segoe UI 保持一致，13px 标题、11–12px 正文，所有按钮保留鼠标入口。

## 已定的行为

- 靠近可互动目标时，在目标附近显示 E 与动作名称。提示不自动执行动作、不打开大卡片；
  点击短提示等同 E。屏幕投影夹在容器内，并避让右上角地图。离开范围后消失。
- 沙发和咖啡在确认交互后直接开始，不再经过第二个确认按钮。左下角约 264px 宽的
  状态卡显示动作、进度和离开方式，不拦截场景点击，也不约束 Tab 焦点。
- E 或 Esc 结束简单休息；WASD、方向键或点击地面可立即离开并延续同一次移动输入。
  清理动作不会丢弃刚指定的新路线；释放设施占位和自动路径，角色正常起身。
- 阅读、街机、备餐、调饮、运动使用左下角约 320px 宽的操作卡，内容按高度限制滚动。
  E/Enter 确认，Tab 或上下键选择；阅读左右翻页，1–3 选择书或食材；Space 也可做
  调饮、运动动作。重复键不重复确认，输入框及聊天里的文字不被活动快捷键消费。
- 街机保留 A/D、左右键接星星；这些键在切换镜头或焦点后仍控制街机。W/S 或 Esc
  可离开。其它设施用 WASD 或 Esc 离开，点击地面可从所有设施离开。
- 关闭按钮仍可使用。对话、会议、群显示和地图的既有功能保留；关闭会议提示和群显示
  不遗留设施锁定。按键作用域随办公室隐藏停用，返回后恢复，后台场景生命周期不变。

## 验证与清理

单元测试覆盖按键分流、街机方向键、重复键、编辑输入和屏幕边界/地图避让。
隔离 mock 浏览器检查各设施的完整键盘路径、首次移动输入、点击地面离开、镜头操作后
街机控制、提示尺寸、窄屏与隐藏场景。运行完整测试、构建一致性及 lint；结束后清理
本任务临时环境、驱动、脚本、测试数据和日志，保留用户请求的预览服务。

2026-10-20 验收：770 项测试全部通过，构建一致性校验通过，lint 通过
（13 条已有警告）。浏览器检查七种设施的键盘操作、连续数字选择、翻页、
调饮/运动节拍、镜头切换后街机方向键、E 离开、首次移动键及首次地面点击。
会议提示与群显示关闭后重新显示附近提示，隐藏办公室时按键不影响场景。
桌面休息卡实测 264×125px，附近提示 134×37px；390px 窄屏休息卡约
264×124px，无横向越界，无浏览器运行时错误。人工查看目标提示、桌面和
窄屏截图；最终效果图作为交付留在项目外，其他测试截图随临时环境清理。
