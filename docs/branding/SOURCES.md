# DeepSeek Office project logo

Asset: `../images/deepseek-office-logo.png`.

Created on 2026-10-19 with the built-in image generation tool for this project's
README and identity. It is a new project emblem, not the official DeepSeek logo.
The selected output is retained without pixel edits: 1254 × 1254, RGBA PNG,
with a genuinely transparent background. The original generated output was
copied into the repository so document readers do not need a local tool cache.

The mark combines an isometric office, two workstations and a speech-bubble
opening, using forest teal, sage and warm oak colors. Both root README files
reference this asset. Existing upstream logo files are retained separately.

## Final generation prompt

```text
Use case: logo-brand. Create an original, distinctive standalone logo emblem for an open-source project named DeepSeek Office, a modern 2.5D office simulation that turns persistent AI teammates and group conversations into an inhabited office. The emblem only, NO TEXT or letters. A compact geometric isometric cutaway office forms a rounded architectural O-like silhouette: two simple office desk stations and two small abstract person markers, integrated with a single subtle speech-bubble negative-space cutout. Must read immediately as office + conversation + collaboration at small sizes. Elegant flat vector-like graphic, crisp consistent geometry, restrained dimensional planes, no photorealistic rendering, no elaborate miniature scene, no excessive tiny details. Use deep forest teal #284e4d, muted sage #91a99a and warm oak gold #c4a475, with small warm-white highlights; all elements should stay legible on both white and dark GitHub pages. Centered emblem fills 80 percent of a square canvas, comfortable clear space. Truly transparent background with alpha, no checkerboard illustration, no surrounding tile or rectangle, no cast shadow beyond the logo. Entirely original identity: no whale, no official DeepSeek logo, no mascot, no copied marks, no watermarks. Output one polished production-ready square logo.
```

## README screenshots

`../images/office-readme-hero.png` and `office-readme-overview.png` are native
browser screenshots of the current 0.6.1 office, captured on 2026-10-19 in an
isolated local mock team. The screenshot browser's clock was set to noon to
show the existing daytime lighting. The scene's own camera and map controls
were used to frame the views; images were not composited or generated.

The meeting, wall-display, lift and shared-sofa gallery reuses previously
recorded functional screenshots. No authentication URLs or real conversations
are included. Characters and messages shown are local test data.
